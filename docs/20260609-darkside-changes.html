2026-06-08 — Darkroom Tagline 差异化

需求：在 Darkroom 模式下显示不同的 tagline（中英文）。

涉及文件：

  • data/site.json — 新增 taglineDarkroom、taglineDarkroomZh 字段
  • lib/data.ts — SiteData 类型 + localizeSite() 函数 + zod schema
  • app/components/pages/HomePage.tsx — 新增 darkroom tagline 的 prop 传递
  • components/HeroCarousel.tsx — tagline 渲染逻辑切换

潜在冲突（已提示用户）：

  • HeroCarousel.tsx 里的 tagline 带有入场动画 + shimmer 效果。切换 darkroom 时如果 tagline 文本变了，动画可能重新触发。
  • site.json 的 zod schema 需要同步更新。
  • 不影响正常模式：正常模式下新增字段不会被读取。

决策（待用户确认后更新）：

  • 方案：条件渲染（双 div 叠放 + CSS display 切换），与 hero 标题切换模式一致
  • 或：动态读取 darkroom 状态切换文本

状态：⏳ 等待用户确认
