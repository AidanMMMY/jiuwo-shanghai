# 酒吧主题网站设计文档

## 1. 项目概述

为一个实体酒吧构建品牌展示网站，面向新客人和熟客两类人群。网站需要传递酒吧的氛围调性，同时提供清晰的酒单、活动照片和实用信息。

核心模块：
- 照片展示（首页 Hero 轮播 + 图文日记瀑布流）
- 画册专辑（按主题分类的相册集）
- 酒单（分类展示，锚点定位导航）
- 酒吧信息（营业时间、地址、联系方式）

## 2. 技术栈

- **框架**：Next.js 15（App Router）
- **语言**：TypeScript
- **样式**：Tailwind CSS
- **数据源**：本地 JSON 文件（`/data` 目录）
- **图片**：存放于 `/public/images`，通过 JSON 引用相对路径
- **部署**：Vercel / Netlify（静态生成 SSG）

## 3. 页面结构

网站共 5 个页面，采用多页面导航结构：

### 3.1 首页（/）
- **Hero 区域**：全屏高度，自动轮播 3–5 张精选氛围照片，5 秒间隔，淡入淡出过渡。底部居中显示酒吧名称 + Slogan。
- **图文日记瀑布流**：按时间倒序展示日记条目。每条卡片包含：封面图、标题、发布日期、正文摘要（取 `content` 前 100 个字符）。点击后进入详情页。

### 3.2 画册页（/gallery）
- **专辑网格**：展示各主题画册封面（如开业派对、调酒师特辑、节日活动）。
- **子页面（/gallery/[album]）**：点击封面进入，以网格形式展示该相册内所有照片。

### 3.3 酒单页（/menu）
- **分类快捷导航**：固定在页面顶部或酒单区上方，列出所有分类（鸡尾酒、威士忌、啤酒、无酒精等）。
- **锚点滚动**：点击分类后平滑滚动到对应区域。
- **酒款卡片**：每个酒款展示名称、价格（琥珀色点缀）、简短描述。

### 3.4 酒吧信息页（/about）
- 营业时间
- 地址 + 嵌入式地图
- 联系电话
- 社交媒体链接
- 酒吧简介 / 品牌故事

### 3.5 日记详情页（/journal/[slug]）
- 展示单条图文日记的完整内容。
- 含返回首页瀑布流的链接。

### 3.6 导航栏
- 固定悬浮于页面顶部。
- 背景为半透明深色，向下滚动后加深至不透明。
- 左侧：Logo / 酒吧名称；右侧：首页、画册、酒单、信息。

## 4. 视觉设计规范

### 4.1 配色
- **主背景**：`#0a0a0a`（深黑）
- **次级背景/卡片底**：`#141414`（炭灰）
- **主文字**：`#f5f5f0`（暖白）
- **次要文字**：`#a0a0a0`（中灰）
- **点缀色**：`#c9a227`（琥珀/铜金），用于价格、悬停状态、当前导航指示
- **分隔线**：`#222222`

### 4.2 字体
- **中文**：系统默认无衬线字体（苹方、思源黑体）
- **英文/数字**：Inter
- 正文保持 16px 左右，标题通过字重（font-weight）而非过大字号来建立层次

### 4.3 组件风格
- **按钮/链接**：幽灵按钮风格（透明底 + 细边框），悬停时填充点缀色并反色文字
- **卡片**：圆角 4–8px，无硬阴影，通过背景色和细边框区分层次
- **图片**：尽量全幅或近全幅呈现，不添加复杂边框，让视觉内容成为主角

## 6. 交互与动效

- **Hero 轮播**：自动播放，5 秒/张，淡入淡出过渡（cross-fade）。
- **导航栏**：始终固定顶部，滚动后背景从不透明深色加深。
- **酒单锚点导航**：点击分类标签后，平滑滚动（smooth scroll）到对应酒品区块。
- **页面入场动画**：主要内容区域在页面加载时执行淡入+轻微上移动效（translate-y: 10–20px），时长约 400–600ms，仅触发一次。
- **链接悬停**：颜色从暖白过渡到点缀琥珀色，过渡时长 200ms。
- **Lightbox（增强交互）**：画册页和日记详情页中的图片支持点击放大全屏查看，可用键盘 ESC 关闭、左右箭头切换。

## 7. 响应式策略

- **桌面端（≥1024px）**：完整展示所有内容，Hero 全屏，画册网格 3 列，酒单双列。
- **平板端（768px–1023px）**：画册网格 2 列，导航保持顶部固定，酒单列数不变或调整为单列。
- **移动端（<768px）**：画册网格 1–2 列，Hero 文字字号适当缩小，导航栏保持简洁，酒单分类锚点导航支持横向滑动。

## 8. 部署与维护

1. 开发完成后，执行 `next build` 生成静态文件（配置 `output: 'export'`）。
2. 将输出目录（默认 `dist`）部署至 Vercel / Netlify。
3. 后续内容更新：编辑 `/data` 目录下的 JSON 文件及 `/public/images` 中的图片，提交后重新触发构建部署即可。

## 9. 后续可扩展点

- 为日记增加标签（tags）和按标签筛选功能。
- 酒单增加「今日推荐」或「季节限定」标识。
- 接入轻量 CMS（如 Sanity），让非技术人员通过后台更新内容。
- 增加「活动/预订」页面，支持表单提交。
